## Overview

Flowframes is a Windows application that uses AI neural network interpolation (RIFE, DAIN, FLAVR) to insert synthetic frames between existing video frames, enabling smooth slow-motion effects and framerate conversion from 24fps to 60fps, 120fps, or higher. It processes any video format via FFMPEG with GPU-accelerated inference on both NVIDIA and AMD hardware.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Flowframes** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **RIFE / DAIN Engines** | Multiple AI interpolation engines selectable by quality and speed |
| **Any Framerate** | Convert source video to any target framerate up to 240fps |
| **GPU Accelerated** | NVIDIA CUDA and AMD ROCm hardware acceleration for fast processing |
| **Format Support** | Processes any video format FFMPEG supports as input and output |
